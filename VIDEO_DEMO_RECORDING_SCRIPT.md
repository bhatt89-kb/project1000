## 🎥 Recording Tips for You:

### Before Recording:
1. ✅ **Clear browser cache** to show fresh load
2. ✅ **Close unnecessary tabs** (only demo tab open)
3. ✅ **Use incognito/private window** for clean demo
4. ✅ **Set browser zoom to 100%** for clarity
5. ✅ **Prepare both PDF files** in easy-to-find folder
6. ✅ **Test upload once** before recording
7. ✅ **Have questions typed in notepad** to copy-paste quickly

### During Recording:
1. ✅ **Move cursor slowly** and deliberately
2. ✅ **Pause 2-3 seconds** after each major action (upload, results appearing)
3. ✅ **Zoom in (Ctrl/Cmd + +)** on important sections:
   - Risk assessment badge
   - Flagged clauses
   - Q&A responses
4. ✅ **Read text slowly** if narrating (or leave silent for voice-over later)
5. ✅ **Show real typing** - don't paste questions instantly
6. ✅ **Wait for results** to fully load before scrolling

### Screen Recording Settings:
- **Resolution:** 1920x1080 (Full HD)
- **Frame Rate:** 30fps minimum
- **Audio:** Record separately if adding voice later
- **Cursor:** Make sure it's visible and highlighted
- **Tool:** OBS Studio (free), Loom, or Windows Game Bar (Win+G)
